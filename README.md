# ZETSU StickerZ
### Crypto Image Engine — Vending Machine Demo

**Created by Artworqq Kevin J. Suber Jr.**  
**A Zetsumetsu Corporation Project**

## Overview

ZETSU StickerZ is a demonstration of a simple crypto image engine, presented through an interactive digital vending machine.

The project was developed to demonstrate how traditional payment systems, decentralized finance (DeFi), web applications, and Discord can interact within a single digital asset distribution system.

The sticker vending machine serves as a working prototype for a much larger concept: **an integrated in-game asset system.**

## Project Purpose

The goal of StickerZ is to demonstrate the fundamental mechanics of a digital vending and asset-delivery system.

The prototype explores:

- **Digital Asset Distribution:** Using a vending machine interface to deliver digital images and collectibles.
- **Hybrid Payments:** Supporting conventional currency transactions alongside cryptocurrency payment systems.
- **DeFi Integration:** Connecting blockchain-based transactions to an application.
- **Web and Discord Interplay:** Demonstrating how an application can operate across a website and Discord.
- **Account-Based Ownership:** Associating acquired assets with individual user accounts.
- **Automated Fulfillment:** Using payment verification to trigger asset selection, delivery, and recording.

## How the Demonstration Works

Users interact with a digital vending machine containing three asset tiers:

| Tier | Discord Price |
|---|---|
| Common | $0.99 |
| Rare | $2.99 |
| Legendary | $4.99 |

Users select a tier and access the available purchase methods. The underlying system is designed to verify payment, select a digital asset, and record it in the user's collection.

The machine uses animated presentation, random asset selection, and account records to demonstrate the process.

## Technology

- HTML, CSS, JavaScript — Application interface
- GitHub Pages — Web hosting
- Supabase — Authentication, database, and backend processing
- Discord — User integration and conventional payment checkout
- Solana — Blockchain transaction infrastructure
- Phantom — Cryptocurrency wallet interaction

## The Larger Concept

**StickerZ is scaffolding for a larger in-game asset system.**

The vending machine demonstrates a basic transaction and distribution process that can be expanded to support digital assets within games and other interactive applications.

Rather than treating the vending machine as the final product, this build establishes foundational mechanics for connecting:

**Payment → Verification → Asset Selection → Delivery → Account Ownership**

These mechanics can become components of a larger digital asset ecosystem.

## Project Status

**Demonstration / Prototype**

StickerZ is an experimental build intended to demonstrate technical concepts and establish reusable application mechanics.

It is not intended to represent the full capabilities of the proposed in-game asset system.
